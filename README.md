
# Branches & Configurations

This repository is organised into different branches tailored for specific operating systems and historical setups. Below is an overview of the available branches:

*   **`master`**: The primary branch containing the default or current configurations.
*   **`arch`**: Dedicated dotfiles and setup configurations optimised for Arch Linux.
*   **`macos`**: Dedicated dotfiles and setup configurations optimised for macOS.
*   **`legacy-*`**: Older and historical configurations retained for reference.
